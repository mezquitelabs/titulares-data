# titulares-data

Datos generados automáticamente por titulares-mx. **No edites esta rama a mano**: se
reemplaza por completo, con un solo commit, en cada publicación.

Los titulares provienen de **medios de terceros**. Cada uno enlaza a su nota original; los
títulos pertenecen a sus medios y aquí no se reclama ningún derecho sobre ellos.

Para pedir que se retire un contenido, abre un issue en
https://github.com/mezquitelabs/titulares-web/issues indicando el enlace.
